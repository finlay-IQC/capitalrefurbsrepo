# Capital Refurbs

Landing page project.

## Uploading images

Drop image files into the folders under `images/`:

| Folder | What goes in it |
| --- | --- |
| `images/logo/` | Logo files (light + dark versions, favicon) |
| `images/hero/` | Big banner / above-the-fold shots |
| `images/projects/` | Before & after job photos, portfolio work |
| `images/team/` | Headshots, van shots, team on site |

Anything that doesn't fit can go straight into `images/` — it can be tidied later.

### Naming

Lowercase, hyphens instead of spaces, and describe what it is:

- `kitchen-refit-hackney-after.jpg`
- `logo-white.png`
- `hero-loft-conversion.jpg`

Avoid `IMG_4821.HEIC` — it says nothing about the picture.

### Formats

- **JPG** for photos
- **PNG** for logos and anything needing a transparent background
- **SVG** for logos if you have one (scales perfectly, tiny file)
- **HEIC** (iPhone default) needs converting to JPG first — iPhone: Settings → Camera → Formats → "Most Compatible" to stop it happening again

### Size

Aim for under 2 MB per image. Straight-off-the-camera photos are often 8–12 MB, which makes a page load slowly. They can be compressed later if needed — upload them anyway rather than not uploading them.
